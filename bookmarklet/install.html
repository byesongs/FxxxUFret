U-FRET → ChordWiki 表示

U-FRETの曲ページを、ChordWikiのレイアウト（コードが歌詞の上に小さく並ぶ表示）で見られるブックマークレットです。

使い方

  1. 下の手順で、ブックマークに登録します（最初の1回だけ）。
  2. U-FRETで曲のページ（https://www.ufret.jp/song.php?data=…）を開きます。
  3. 登録したブックマークを押すと、その曲がChordWikiのレイアウトで表示されます。もう一度押すか「×」で元に戻ります。

表示中は、カポ（U-FRETの「★簡単弾き」が初期値）と移調を変えられます。ChordWiki形式のテキストのコピーと印刷もできます。

登録のしかた

パソコン（Chrome・Edge・Firefox・Safari）

このボタンをブックマークバーへドラッグしてください。

ChordWiki表示 ブックマークバーが見えないときは Ctrl+Shift+B（Mac は ⌘+Shift+B）

スマホ（iPhone の Safari・Android の Chrome）

  1. このページをブックマークに追加します。
  2. 下の「コードをコピー」を押します。
  3. 追加したブックマークを編集し、名前を「ChordWiki表示」に、URL をコピーしたコードに置き換えて保存します。
  4. U-FRETの曲ページで、 iPhone はブックマーク一覧から「ChordWiki表示」を選びます。 Android の Chrome はアドレスバーに「ChordWiki表示」と入力し、候補に出たブックマークをタップします。

ユーザースクリプトを使う場合

Tampermonkey・Violentmonkey（iPhone は「Userscripts」アプリ）を使っている場合は、ufret2cw.user.js を導入してください。U-FRETの曲ページの右下に「ChordWiki表示」ボタンが出るようになります。
